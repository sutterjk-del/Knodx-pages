# knodx-pages

Funnel and landing pages for knodx.io. Each top-level folder is one page, served at knodx.io/lp/<folder>/.

Rules
- `main` is what's live. Merging to `main` = publishing. Jordan approves every merge.
- Pages are public: never commit keys, passwords, customer data or .env files.
- `.htaccess` blocks web access to `.git` and repo files. Don't remove it.
